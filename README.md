# tradeclerks.com

Holding page, Terms and Privacy for the Trade Clerks app, served by GitHub Pages.

- The legal text lives in `content/*.md`, copied from `docs/legal/` on the app repo's `main` (the source of truth): `terms.md` and `privacy.md` by name, nothing else from that folder, never from an unmerged branch.
- To change it: copy the two files in, and set the effective date in the copies only (the source keeps `[publish date]`) to the day Steve will merge. Check each copy differs from the source only on that line and shows the same version as the app's `TERMS_VERSION`. Run `python3 build.py`, then open a pull request. If the merge moves to another day, change the date in both copies and rebuild before merging.
- A merge or push to `main` publishes the site straight away through GitHub Pages, so nobody pushes to `main`, and only Steve merges.
- The customer page (`v/index.html`) shows an invoice or quote from the link in the email. An open quote's total is worked out on the page as the customer ticks options, and must equal what the server stores on acceptance (each tax rounded to the cent on its own, a half cent up). That working-out sits between the `@quote-total` marks and is tested: `node --test tests/quote-total.test.mjs` before any pull request that touches it. `tests/quote-cases.json` is a copy of the quotes the app repo holds its phone code and test database to (`supabase/tests/audit/65_money_rounding_test.sql`); a case changed there is copied here. When the test reports the copy check as skipped (no app repo found beside this one), run it again with `TRADE_CLERKS_APP=<path to the app repo>` before a pull request that changes the cases. `tests/` is never published (`_config.yml`).
